# Banglauru House  Price Prediction
ye ML project Bangalore ke ghero ke price predict kerta hai.

## File in this project
- 'main.py' - Flask web app
- 'RidgeModel.pkl' - Trained ML model
- 'index.html' - Website UI
- 'Bengaluru_House_Data.csv' - Dataset
- 'Cleaned_data.csv' - Cleaned Dataset

## kaise chalaye
1. 'pip install -r requirement.text'
2. 'Python main.py'
3. Browser me 'localhost:5000' open kero
