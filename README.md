# Banglauru House  Price Prediction

Bangalore ke ghero ke price predict kerne wala Machine Learning prject.
Ridge Regression model use kiya gaya hai.

## Project ke baare me 
ye web app user se ghar ki details leta hai-Location, BHk, Bathrooms, sqft aur  uske basis pe house price
predict karta hai.

## Tech Stack
**Backend**: Python, Flask
**ML**: Scikit-learn, Ridge Regression, Pickle
**Data**: Pandas, Numpy
**Frontend**: HTML, CSS

## File in this project
- 'main.py' - Flask web app - website chalata hai
- 'RidgeModel.pkl' - Trained ML model
- 'index.html' - Website UI
- 'Bengaluru_House_Data.csv' - Dataset
- 'Cleaned_data.csv' - Data clearningke baad wala dataset
